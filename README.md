# Undertaken with Urgency: Neutering Your Ancestors (UwU NYA)
Warhammer 40,000 themed wallpapers. Mainly in 1080p 16:9. Intended for use with the Darktide mod [Improved Loading Screens](https://www.nexusmods.com/warhammer40kdarktide/mods/1012) (ILS); these are all from my [Custom Loading Backgrounds](github.com/Backup158/DarktideCustomLoadingBackgroundsList/tree/main) (CLB) list.

This is all of them, though unlabelled. Since that doesn't really matter in this context, I think that's good enough. I have an alternative repo, [Obtained with Ostentation](https://github.com/Backup158/darktide_improved_loading_screens_list_owo), that only contains wallpapers that are clearly named. Honestly, that's a bit overkill.
