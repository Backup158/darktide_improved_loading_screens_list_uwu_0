# Undertaken with Urgency: Neutering Your Ancestors (UwU NYA)
Warhammer 40,000 themed wallpapers. Mainly in 1080p 16:9. Intended for use with the Darktide mod [Improved Loading Screens](https://www.nexusmods.com/warhammer40kdarktide/mods/1012) (ILS); these are all from my [Custom Loading Backgrounds](https://www.nexusmods.com/warhammer40kdarktide/mods/462) (CLB) [album](github.com/Backup158/DarktideCustomLoadingBackgroundsList/tree/main).

This is the entire album, albeit unlabelled. Since that doesn't really matter in this context, I think that's good enough. I have an alternative repo, [Obtained with Ostentation](https://github.com/Backup158/darktide_improved_loading_screens_list_owo), that only contains wallpapers that are clearly named. Honestly, that's a bit overkill.

Here's some extension album repos:
- [Undertaken with Urgency: Neutering Your Aggressive Animals](https://github.com/Backup158/darktide_improved_loading_screens_list_uwu_nyaa) - Wallpapers from *Warhammer 40,000: Gladius - Relics of War*
- [Undertaken with Urgency: Neutering Your Auntie's Aging Aardvark](https://github.com/Backup158/darktide_improved_loading_screens_list_uwu_nyaaa) - Wallpapers that are not 16:9 but go hard regardless

## Swapping from CLB
From what I could tell, CLB loads everything at the start, while ILS only loads one thing before a loading screen. That makes it not swap mid-loading screen, but should be more performance friendly. >700 wallpapers at startup, even with parallel processing, is a lot.

Both still work, but I'll stick with ILS at this point.
